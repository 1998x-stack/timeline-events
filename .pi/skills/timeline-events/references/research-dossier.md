# 深度研究专题规范

适用：政治人物的崛起、并购事件、政策变迁的多层因果解释。

## 必须做的三层审查

1. **事实层**：事件何时发生、主体是谁、有什么可追溯的正式文件。重要数值优先原始报告。
2. **关联层**：哪些正式共事、推荐、任命、董事会或交易顾问关系被原始资料或可核的报道明确支持。
3. **因果层**：不能由相同城市、学校、家庭婚姻、参加同一会议直接推断权钱交易、选举操纵或其他违法行为。

## JSON 字段

在经过核验的时间轴 JSON 中添加 `research` 对象：`headline`, `summary`, `metrics[]`, `chapters[]`, `connections[]`, `claim_audit[]`, `hypotheses[]`, `methodology[]`。重要段落通过 `source_ids` 关联顶层 `sources`，不允许无来源的强断言。每条记录的 URL 应指向可公开阅读或辨识的正式材料/媒体原文。

## 边界

- 主张核验结果使用“可核实、部分属实、需要限定、数据不符、缺乏证据”等显式标签。
- “未找到足够证据”不等于断言“事件绝不可能发生”；无证据的私人指控不得被洗成事实。
- 不把人的宗教、族裔身份或出席社交组织的事实当作集体秘密操纵的证据。
- 原图内容应按用户原样转录时使用 transcription 模式，与核验后的 research 模式不能混同。
- 客户端 JavaScript 仅负责筛选和交互，正文与引用在无 JS 环境中可读。

参考输入：`examples/emmanuel-macron-rise.json`。
