# HTML 图像级复刻设计规范（v2）

## 1. 目标与取舍

参考图分辨率 **2048 × 1280**，比例 **8:5**。此版本的视觉工作是将图片内容转换为可选中、可访问、可编辑的 HTML/CSS 元素，不把原图当背景、不在 SVG 里嵌入整张参考图。可容忍浏览器间字体微差；必须保持关键位置、层级、文字、节点方向、配色、背景留白相近。

复刻与内容考证是独立维度：原图中的 2026 年事件、司法裁定与 APEC 相关表述不自动视为正确。使用 `reference_transcription` 时仅忠实排版，在文章下方可见地提醒未核验。

## 3. 精确桌面与可用移动端

- **桌面**：固定设计板 2048×1280，用 `ResizeObserver` 计算比例，将整个设计板按可用宽度等比缩放，确保元素相对位置保持一致。
- **手机**（默认 < 760 px）：切换为纯 DOM 垂直事件列表，避免把 2048px 宽画布缩小到无法辨认。改用自然流布局、清晰的日期、阶段与提示卡。
- **单文件**：生成 HTML 内联 CSS；JS 只负责缩放。无外部 API、无字体 CDN，尽量支持离线打开。
- **可访问性**：阅读结构必须由 `h1/h2`、`ol/li`、`article/section`、`time` 等构成。不能只提供 canvas 或图片作为唯一正文。
- **打印**：保留白底，避免强制将低分辨率 PNG 放大。

## 4. 完整性约束

- 桌面图节点 4–10 个（图片参考为 10）；更多节点应分篇，不做 15 个节点的超密排版。
- 上下交错可预测：索引偶数放上方，奇数放下方；末节点红色。
- 日期保留内部精度，界面可以显示 `YYYY.MM`；时间跨度从首尾节点自动计算。
- 标题、描述、阶段和阅读提示必须先做字数与实际渲染边界检查，避免元素间碰撞。
- 所有动态字符串经 HTML escape；不得从数据字段直接执行 HTML/JS。
- 对比图以用户上传的 `image(20261122-050934).png` 为参考，不应该存储用户原图在公共仓库作为“官方资料图”，除非明确授权。

## 5. 可检查的视觉回归

本地有浏览器时建议生成 2048×1280 截图，检查：标题垂直位置、概览框尺寸、节点 x 坐标、卡片起点、页脚是否在画布以内；用图像差异辅助识别溢出，不以像素百分百相等作为跨平台字体目标。
