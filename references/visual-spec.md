# 视觉规范｜财经时间轴版式 v1

## 与参考图对应的视觉元素

- 画布：3200×2000、白底，高分辨率横版。
- 顶部：深色粗标题、左对齐；标题下面一条深蓝细线；下方浅灰说明。
- 信息概览：大圆角浅蓝框，显示事件区间、自动计算的年月历时与节点数。
- 中轴：深蓝水平线，事件按顺序沿轴等距摆放，蓝色历史节点；最后节点红色。
- 日期：全部以 YYYY.MM 显示；原 JSON 内仍保留精确日期。
- 事件：日期、短标题、核验过的一句话；从左到右，上下交错排列。
- 底部：最多四个阶段说明、最多三条总结、资料来源数量和明确的“等距不代表时间比例”脚注。
- 基础色：#153847（深蓝主轴）、#377fa8（历史节点）、#bc2433（最后节点）、#74878f（副标题）。
- 字体：优先 Noto Sans CJK SC；若系统未安装，先安装，不能接受方框字。

## 文本与布局约束

每张图 4–10 个节点、阶段不超过四个；过多节点分图。节点标题最多两行；描述最多三行；每个节点显示的内容应该是经编辑的短句，图外证据文档承载全部来源和详细上下文。

渲染器每个事件的描述最多约十个全角汉字/行，上下交错留白避免碰撞。文本不是自动缩小到无法阅读，而是拒绝不适合当前版式的 JSON。SVG 保留矢量文字；PNG 通过 CairoSVG 转换生成。

## 重要的非映射说明

轴上节点 **按照展示顺序等距分布**。不能据相邻距离推断事件间隔。起始结束时间从数据自动推导，年月跨度也从首末节点计算。

## 原图版权和风格

借鉴公开可见的版式要素，而不是复制用户参考图的署名或水印。避免假冒原图片出品机构。若用户提供可使用的完整模板与授权，后续可增加选用模板的功能。
