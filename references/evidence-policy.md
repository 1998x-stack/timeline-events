# 研究与证据规范

## 最低证据清单

每个节点需要一个具体时间、主体、动作与真实 URL。如果来源只证明“宣布计划”，不要写成“已实施”；如果报道在事件发生之后发出，则事件日期应采用原事实日期，而不是新闻发布日期。

对于关税、法律、战争、财务等议题，特别区分：

- 数量的单位：亿美元与亿美元商品范围、税率与上升的百分点、名义与实际、单一商品税率与总体税率。
- 状态：提出、启动、签署、生效、暂停、恢复、取消、终止。
- 口径：官方声明、可独立确认的事实、研究者推断、尚存争议的观点。
- 截止日：动态事件明确最新已检查的 YYYY-MM-DD；不要假装内容实时更新。

## 两步校验

**第一遍：原始证据比对。** 阅读对应来源原文，对照时间、主体和行为；数值有复杂定义时，应保留足够精确的限定语。

**第二遍：反证检索。** 对事件转折与争议说法，检索另一可信来源查错。如果存在冲突，修订图内表述并在来源文档补注，不要平滑掉矛盾。

## 来源质量

优先官方原始文件及学术原始研究；新闻用于补足日期与语境。source_ids 必须指向 sources 的 id，不接受 example.com 等占位网址用于正式发布。CLI 只验证 URL 语法与引用完整性，**不能自动确认页面内容支持句子**，这必须由 Agent 或人工完成。

## 生成模式

严格模式：如核心节点无法核验，则拒绝将该节点写为确定事实。宽松探索模式只允许先出草稿 JSON 并注明 [待核实]，不得把草稿作为最终信息图交付。

图片底部只容纳概括来源；完整原始网址和节点映射保存在同名 .sources.md。
